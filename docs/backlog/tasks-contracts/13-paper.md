## Objetivo y estado

Comprar únicamente papel adhesivo compatible; no comprar impresora ni reconstruir códigos. Este issue da seguimiento humano y no ejecuta una compra.

Estado de seguimiento: solicitado / pendiente de verificación de entrega. El trabajo local o la auditoría inicial no equivalen a funcionalidad integrada ni pruebas aprobadas.

## Criterios de aceptación

- [ ] Confirmar modelo de impresora existente, consumible y tamaños admitidos antes de elegir papel.
- [ ] Relevar papel adhesivo para etiquetas medianas/grandes compatible y registrar especificación/cantidad/cotización para revisión humana.
- [ ] Coordinar adquisición con responsable humano; registrar estado/recepción sin publicar datos de pago.
- [ ] Mantener compra separada de desarrollo y ensayo físico; el agente de software no compra productos.

## Alcance y coordinación

Compras/secretaría; responsable pendiente. No incluye equipos ni desarrollo.
